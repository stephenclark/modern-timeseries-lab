# Modern Time Series Lab

A portfolio and learning laboratory for modern time-series forecasting.

The project progresses from classical statistical forecasting through machine
learning and deep learning to modern time-series foundation models, with a
particular emphasis on TimesFM 3.0.

## Themes

- Time-series analysis and diagnostics
- Forecast evaluation and temporal cross-validation
- ARIMA, ETS and state-space models
- Hidden Markov and regime-switching models
- Machine-learning forecasting
- LSTM and sequence models
- Modern neural forecasting
- Probabilistic forecasting
- Foundation models, particularly TimesFM 3.0
- Multivariate and covariate-aware forecasting
- Hierarchical forecasting
- Spatiotemporal forecasting
- Reproducible research and ML engineering

## Domains

Examples focus where possible on:

- economics
- finance
- labour markets
- social data
- population
- geospatial data
- Australian public-sector datasets

## Repository structure

`chapters/` contains individual learning projects.

`src/tsportfolio/` contains reusable Python code shared between projects.

`data/` contains local data products. Large or reproducible source datasets are
not committed to Git.

`tests/` contains automated tests for data, forecasting and shared code.

`capstone/` contains the final integrated forecasting project.
